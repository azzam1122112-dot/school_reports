{% translate "1. التعريف ونطاق الخدمة" %}

{% translate "منصة توثيق هي منصة برمجية سحابية لإدارة التقارير المدرسية، وملفات الإنجاز، والطلبات، والتعاميم، والمخرجات بصيغة PDF، وخدمات الأرشفة الاختيارية. العميل هو المدرسة أو الشخص المخول بالتعاقد نيابةً عنها، والمستخدم هو من تمنحه المدرسة حسابًا وصلاحية." %}

{% translate "تُعد هذه الشروط، وصف الباقة، والسعر الإجمالي الظاهر قبل الدفع، وسياسات الخصوصية والاسترجاع وتقديم الخدمة أجزاءً من العقد الإلكتروني." %}

{% translate "2. إنشاء الحساب وصحة المعلومات" %}

  • {% translate "يقر منشئ حساب المدرسة بأنه مخول بذلك، وأن البيانات المدخلة صحيحة ومحدثة." %}
  • {% translate "تتحمل المدرسة مسؤولية إدارة مستخدميها وصلاحياتهم والمحافظة على بيانات الدخول." %}
  • {% translate "يجب عدم رفع محتوى غير مشروع، أو مخالف لحقوق الغير، أو لا تملك المدرسة صلاحية معالجته." %}
  • {% translate "يجوز إيقاف الوصول مؤقتًا عند وجود خطر أمني أو استخدام مخالف، مع إشعار العميل متى كان ذلك ممكنًا." %}

{% translate "3. الباقات والأسعار والدفع" %}

{% translate "تظهر خصائص كل باقة ومدتها وسعة المعلمين وسعرها بالريال السعودي في قسم «المنتجات والخدمات والأسعار». الأسعار المنشورة هي المبالغ النهائية المطلوبة، ولا توجد ضريبة قيمة مضافة. إذا تغير الوضع الضريبي مستقبلًا فسيُوضّح السعر الإجمالي وأي ضريبة أو تكلفة إضافية قبل تأكيد الطلب." %}

{% translate "لا يتجدد الاشتراك المدفوع تلقائيًا ما لم تُعرض آلية تجديد تلقائي بوضوح ويحصل مقدم الخدمة على موافقة صريحة من العميل. يبدأ الاشتراك بعد قبول الدفع والتحقق اللازم وفق سياسة تقديم الخدمة." %}

{% translate "4. التزامات مقدم الخدمة" %}

  • {% translate "تقديم الوظائف المشمولة في الباقة خلال مدتها، مع صيانة المنصة وتطبيق إجراءات أمن مناسبة." %}
  • {% translate "إظهار أي انقطاع مخطط أو تغيير جوهري في الخدمة، ومعالجة الأعطال ضمن حدود معقولة." %}
  • {% translate "عدم تغيير السعر أو النطاق على اشتراك مدفوع خلال مدته إلا بموافقة العميل أو لسبب نظامي." %}
  • {% translate "توفير قنوات واضحة للدعم والشكاوى والاسترجاع." %}

{% translate "5. المحتوى والملكية الفكرية" %}

{% translate "تبقى بيانات المدرسة ومحتواها مملوكة لها أو لأصحاب الحقوق فيها. يحتفظ مقدم الخدمة بحقوق البرمجيات والتصميم والعلامة والمحتوى العام. يمنع نسخ المنصة أو تفكيكها أو محاولة تجاوز ضوابطها أو استخدامها لتقديم خدمة منافسة دون تصريح." %}

{% translate "6. الإلغاء، انتهاء الاشتراك، والمسؤولية" %}

{% translate "تخضع طلبات الإلغاء والاسترداد لسياسة الإلغاء والاسترجاع والحقوق المقررة نظامًا. عند انتهاء الاشتراك قد يتوقف إنشاء محتوى جديد أو بعض الوظائف؛ وعلى العميل تنزيل ما يحتاجه خلال المدد الموضحة له. لا يحد أي نص هنا من حق نظامي لا يجوز الاتفاق على إسقاطه." %}

{% translate "لا يكون مقدم الخدمة مسؤولًا عن تعطل سببه جهاز العميل أو اتصاله أو خدمة خارج سيطرته، مع بقائه مسؤولًا عن التزاماته النظامية وعن معالجة الخلل الذي يقع ضمن نطاق المنصة." %}

{% translate "7. الأنظمة وتسوية النزاع" %}

{% translate "تخضع العلاقة لأنظمة المملكة العربية السعودية. يبدأ حل أي خلاف عبر قناة الشكاوى، دون إخلال بحق العميل في اللجوء إلى وزارة التجارة أو الجهات المختصة والمحاكم السعودية." %}
